# Flag Artwork Sources

Most source artwork comes from lipis/flag-icons under the MIT license; see LICENSE.flag-icons.
The regional replacements below retain their own source licenses. Their use as regional icons does not imply official flag status.

Adaptations by zwjtano/icons: shared waving geometry, watercolor paper material, ink outline and transparent PNG conversion. Original creators do not endorse this icon pack.

## Search Names

Localized territory names are drawn from [Unicode CLDR](https://github.com/unicode-org/cldr-json). Stable image filenames remain unchanged; bilingual names are placed in the client-facing name field.
