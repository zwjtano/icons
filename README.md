# 水彩图标

## 项目介绍

- **图标风格**：手绘水彩、纸张纹理与圆角底板，PNG 外缘透明。
- **收录内容**：流媒体、社交、AI、游戏、云服务等应用，以及机场、VPS、Emby、七大洲地图、国家及地区旗帜和地图旗帜。
- **适用客户端**：Loon、Surge、Quantumult X 等客户端；支持中英文名称搜索。
